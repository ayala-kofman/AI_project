# בוט ידע ארגוני - RAG System

מערכת שאלות ותשובות המבוססת על מסמכים ארגוניים, עם LlamaIndex + ChromaDB + Gemini.

## הרצה מהירה

```bash
# 1. התקן תלויות
pip install -r requirements.txt

# 2. צור קובץ .env
cp .env.example .env
# ערוך .env והכנס את ה-API key שלך

# 3. הוסף מסמכים לתיקיית data/

# 4. הפעל
streamlit run app.py
```

## החלטות טכניות

| פרמטר | ערך | סיבה |
|--------|-----|-------|
| Chunk size | 512 טוקנים | איזון בין הקשר לעלות |
| Chunk overlap | 50 טוקנים | מניעת חיתוך משפטים |
| TOP K | 3 | מספיק הקשר, מינימום רעש |
| Query expansion | פעיל | שיפור איכות חיפוש לשאלות קצרות |
| Search type | Similarity (cosine) | סטנדרט, מהיר ואמין |
| Embedding model | text-embedding-004 | חינמי, איכותי |
| Generation model | gemini-1.5-flash | חינמי, מהיר, זול |
